Validation scope:
All 1,296 PastOnly files and 1,080 future files were deserialized one file per CPU worker, with at most four workers. Every graph was checked for feature/target/history dimensions, CNN grid sizes, pressure metadata shape, and supervised timestamps. Actual target hours were checked for duplicates and chronological split separation. Numerical target/pressure values and raw-pressure transformation/forcing finiteness were checked at least on the first and last graph of every file; several cached initial pairs had all target/pressure values checked. This is not a bytewise checksum or exhaustive finiteness scan of all forcing tensors.

- Historical checkpoints do not exist until training completes. End-to-end inference with trained weights is deferred; source and interface checks passed.
- Numerical payload checks are sampled at file boundaries as detailed in the dataset audit; all graph shapes and target timestamps were checked.
