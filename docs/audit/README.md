# Historical audit evidence

This directory preserves comparisons, inventories, source hashes, diffs and test logs from earlier revisions. Their filenames, interface names and results describe those revisions, not current production behavior. They are not imported by training or inference. In particular, records of removed objectives and metric names remain historical evidence; they are not compatibility fixtures.

Use the root README, CHECKPOINT_SELECTION.md and EXCESS_AMPLITUDE.md for the current interface. Rerun current tests to validate current code; do not interpret historical source inventories as hashes of today's tree.
